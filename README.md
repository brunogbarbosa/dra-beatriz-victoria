# Dra. Beatriz Victória

Site editorial de harmonização orofacial, adaptado do template Premium Vendas V4. Inclui hero com retrato real e iluminação preservada, narrativa de apresentação, seis comparativos de resultados, agendamento pelo WhatsApp, navegação responsiva e favicon BV.

## Desenvolvimento

Requer Node.js 20.9 ou superior.

```sh
npm ci
npm run dev
```

## Verificação

```sh
npm run typecheck
npm run build
```

## Vercel

Importe este repositório na Vercel. O framework é Next.js, o diretório raiz é `./` e os comandos padrão de instalação e build são suficientes. Não há variáveis de ambiente obrigatórias.
